# 多智能体虚假新闻对抗模拟（初始版本）

本仓库实现了《结构框架.md》中描述的多智能体对抗式虚假新闻模拟系统的首轮代码骨架。

## 目录结构

- `src/multiagent_sim/`
  - `agents/`：生成器、检测器、用户等代理抽象与实现。
  - `community/`：用户画像、社交图谱与经验记忆等社区建模组件。
  - `core/`：仿真编排器、事件与配置等核心流程逻辑。
  - `optimization/`：生成器与检测器策略优化器占位实现。
  - `pipelines/`：高层工作流（数据注入、仿真、评估）。
  - `scoring/`：得分与反馈计算工具。
  - `tools/`：Wikipedia 搜索等外部工具封装。
  - `utils/`：日志、ID 生成、解析等通用工具。
  - `data/`：留给数据存储或数据集接口的扩展位置。
- `tests/`：后续单元 / 集成测试（当前为空）。

## 环境准备

1. 使用 Python 3.10+ 创建虚拟环境。
2. 安装依赖：`pip install -r requirements.txt`。
3. 在运行前设置必要的环境变量：
   - `OPENAI_API_KEY`

> 注意：仓库不包含任何密钥，需在本地自行配置。

## 使用方式

骨架代码对外暴露 `SimulationOrchestrator`，在 `run_simulation.py` 中给出了最小示例，可直接执行：

```
python run_simulation.py
```

示例会：
- 根据用户画像构建社群与社交边；
- 调用生成器创建伪造新闻并记录操作日志；
- 按设定轮次在网络中传播，收集用户意见；
- 调用检测器（可选工具调用）给出真伪判定，并回写经验记忆与策略反馈。

## 当前状态

- 代码以低耦合模块呈现，便于替换具体模型 / 策略。
- 生成器与检测器默认假设 LangChain + OpenAI 接口可用，且输出 JSON 字段；若模型返回非结构化文本，内部解析器会自动兜底。
- 多轮传播、策略优化接口已预留，当前实现为占位逻辑，可逐步补充真实算法。
- Serper 工具需要外网访问；如需离线调试，可在 `src/multiagent_sim/tools/search.py` 中替换为本地 mock。

## 后续建议

- 根据研究需求补充更细致的用户画像、传播规则以及得分函数。
- 在 `tests/` 目录添加针对关键组件的单元测试，保障后续扩展稳定性。
- 若计划部署到生产环境，建议将 API 调用层抽象成可配置的服务适配器，并完善日志 / 持久化方案。
